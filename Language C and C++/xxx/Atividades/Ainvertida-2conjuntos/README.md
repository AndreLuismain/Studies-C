# Aula Invertida 2 — Operações de Conjuntos com Deduplicação *In-Place*

## Objetivo e Conceitos Aplicados
Algoritmos sobre vetores de inteiros em C++ para remoção *in-place* de elementos repetidos (com deslocamento de memória e atualização do tamanho lógico), geração do conjunto **União** ($A \cup B$) e do conjunto **Interseção** ($A \cap B$).

## Como Compilar e Executar
```bash
g++ main.cpp -o conjuntos -Wall
./conjuntos
```
