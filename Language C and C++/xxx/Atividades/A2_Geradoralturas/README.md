# Atividade 2 — Gerador Estocástico de Alturas e Estatísticas $O(n)$

## Objetivo e Conceitos Aplicados
Geração de `1.000` amostras de alturas em ponto flutuante no intervalo $[1.50\text{m}, 2.30\text{m}]$, calculando média aritmética, extremos (maior e menor altura) e percentual de amostras acima de $2.00\text{m}$.

## Como Compilar e Executar
```bash
g++ main.cpp -o a2_alturas -Wall
./a2_alturas
```
