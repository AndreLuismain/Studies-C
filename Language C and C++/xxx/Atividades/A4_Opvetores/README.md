# Atividade 4 — Operações Avançadas em Vetores Estáticos

## Objetivo e Conceitos Aplicados
Menu interativo com 7 algoritmos sobre um vetor de `1.000` inteiros em $[100, 200]$:
- Busca da primeira ocorrência e contagem total de frequência;
- Filtragem por intervalo $[a, b]$;
- Inversão *in-place* em $O(n)$ trocando extremos simétricos;
- Remoção com deslocamento à esquerda (*left-shift*) e deduplicação.

## Como Compilar e Executar
```bash
g++ main.cpp -o a4_opvetores -Wall
./a4_opvetores
```
