# Atividade 3 — Processamento de Cena Gráfica 2D e 3D via Arquivo

## Objetivo e Conceitos Aplicados
Leitura sequencial do arquivo `cenagrafica.txt` até a palavra-sentinela `"fim"`, acumulando a área superficial total e o volume total das primitivas 2D (quadrado, retângulo, triângulo, círculo, trapézio) e sólidos 3D (cubo, paralelepípedo, cilindro, cone, esfera).

## Como Compilar e Executar
```bash
g++ main.cpp -o a3_cenagrafica -Wall
./a3_cenagrafica
```
