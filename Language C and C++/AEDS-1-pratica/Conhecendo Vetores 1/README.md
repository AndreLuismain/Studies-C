# Conhecendo Vetores 1 — Operações de Conjuntos em Arrays

## Objetivo e Conceitos Aplicados
Modelagem de operações de **Teoria dos Conjuntos** sobre vetores estáticos de inteiros em C++:
- Remoção manual de elementos duplicados;
- Construção do conjunto **União** ($A \cup B$) e do conjunto **Interseção** ($A \cap B$).

## Como Compilar e Executar
```bash
g++ main.cpp -o vetores1 -Wall
./vetores1
```
