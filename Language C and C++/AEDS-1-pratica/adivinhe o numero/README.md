# Jogo Interativo — Adivinhe o Número

## Objetivo e Conceitos Aplicados
Aplicação interativa em C++ paraexercitar estruturas de repetição condicional (`while`) e validação de entrada:
- Sorteio pseudoaleatório no domínio $[1, 100]$;
- Validação de limites de tentativa, dicas direcionais (maior/menor) e contagem de iterações.

## Como Compilar e Executar
```bash
g++ main.cpp -o adivinhe -Wall
./adivinhe
```
