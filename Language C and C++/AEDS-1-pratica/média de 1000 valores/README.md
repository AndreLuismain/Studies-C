# Estatística Descritiva sobre 1.000 Valores em Ponto Flutuante

## Objetivo e Conceitos Aplicados
Simulação estatística em C++ de `1.000` alturas humanas geradas aleatoriamente no intervalo $[1.50\text{m}, 2.30\text{m}]$:
- Determinação do valor máximo, valor mínimo e média aritmética em passagem única $O(n)$;
- Contabilização condicional de indivíduos com estatura superior a $2.00\text{m}$.

## Como Compilar e Executar
```bash
g++ main.cpp -o media1000 -Wall
./media1000
```
